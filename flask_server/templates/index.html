操作教學

切換模式

  • 張開手掌停住 1 秒：切換模式
  • F按 F：切到 Focus Mode
  • M按 M：切到 Virtual Mouse
  • UI點上方按鈕：手動切換模式

Focus Mode

  • 左右揮動：切換餐點
  • 握拳：進入數量調整
  • 拇指向上：增加數量
  • 拇指向下：減少數量

Virtual Mouse

  • 手掌離中心：移動游標
  • 拇指點擊：滑鼠左鍵
