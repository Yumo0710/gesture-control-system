手勢教學

切換模式

  • 張開手掌停留 1 秒：切換模式
  • F按 F：Focus Mode
  • M按 M：Virtual Mouse

Focus Mode

  • 左右滑：切換餐點
  • 上滑：增加數量
  • 下滑：減少數量
  • OK 手勢：第一次開明細，第二次送出訂單

Virtual Mouse

  • 手掌偏移：控制滑鼠游標
  • 拇指點擊：滑鼠左鍵
